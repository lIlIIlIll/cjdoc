# 预览文档并随修改重建

启动 `cjdoc serve` 后，在浏览器里阅读本地站点。保存源码或指南的修改，cjdoc 会重新生成页面；刷新浏览器即可看到新内容。

## 前提

- 已完成[首次生成教程](../tutorials/first-site.md)，从 `docdemo/` 项目根开始。
- 已安装 `cjdoc`，当前终端已加载仓颉 SDK 环境。
- 本例使用 `127.0.0.1:8080`，该端口需要空闲。预览只监听回环地址，不作为公网服务器。

## 启动预览并打开页面

从项目根启动服务，让这个终端保持运行：

```bash
cjdoc serve --project . --port 8080
```

终端会显示本地 URL；初次生成成功时显示 `serve: generated html`。在浏览器打开 `http://127.0.0.1:8080/`，进入 `docdemo` 包的 `greet` 页面。

也可以启动时加 `--open` 请求自动打开浏览器。如果系统无法启动浏览器，手动打开终端显示的 URL 即可。

## 修改注释并刷新

保持服务运行，用编辑器打开 `src/api.cj`，把 `greet` 的摘要一行改为：

```text
 * 为指定名字生成问候语。
```

保存文件，等服务终端再次显示生成成功，然后刷新浏览器。`greet` 的摘要应变成这句新说明。预览会监视源码、Markdown、`cjpm.toml` 和 `cjdoc.toml`；已[加入指南](../tutorials/add-guides.md)时，也可以编辑指南正文后保存、刷新。

这不是浏览器自动刷新功能。看到服务生成成功后，仍需刷新页面；不要手工编辑输出目录里的 HTML。

## 停止预览

在运行服务的终端按 `Ctrl+C`。终端返回提示符后，预览服务已经停止；后续需要独立静态站点时运行[生成与发布](generate-and-publish.md)中的命令。

## 更换端口

如果启动时报端口占用，停止占用该端口的预览，或换一个空闲端口重新启动：

```bash
cjdoc serve --project . --port 8081
```

浏览器地址也要改为 `http://127.0.0.1:8081/`。

## 重建失败时查看错误

如果保存后终端显示生成失败，先阅读最新诊断，修正对应源码、指南或配置，再保存。之前已有成功站点时，服务会继续提供那份页面；因此“页面还能打开”不表示最新修改已经生成。

需要从另一个终端查看最近一次构建状态时，可选用 `curl` 读取状态接口：

```bash
curl -fsS http://127.0.0.1:8080/__cjdoc/status.json
```

`status` 为 `ok` 表示最近一次构建成功；为 `error` 时查看 `lastError`。如果改过端口，状态 URL 使用相同端口。修正输入后等待重建，看到 `ok` 再刷新页面。全部状态字段见[CLI 的 serve 参考](../reference/cli.md#serve)。

若是输出目录或锁冲突，先停止仍运行的生成或预览，按[管理输出](manage-outputs.md)处理；不要删除无法确认归属的锁。
